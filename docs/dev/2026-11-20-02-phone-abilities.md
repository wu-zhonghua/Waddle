# 让 Waddle 里的 Codex 用上手机能力：短信、通讯录、日历、文件等（3 个阶段）

- 状态：待实现（阶段 1）
- 日期：2026-11-20
- 上一份：无（基于 2026-11-19-01 已实现能力）
- 涉及：安卓

## 现在的样子

Waddle 里的 Codex 能读写 Waddle 自己目录里的文件、跑命令，手机能力只有一点：读五项系统设置、改屏幕亮度。这两个是上一份需求为了验证能不能接手机能力做的测试。用户真正想要的是通用助手：在手机上随口让 Codex 做事，比如「最近的验证码是多少」「把上周银行发的短信汇总一下」「明天下午有什么安排」，现在都做不到。

## 要做什么

用户在 Waddle 的 Codex 对话里用平常的话提要求，Codex 需要时去用手机上对应的能力，把结果告诉用户。每种能力用户自己决定开不开，开了以后在对话里直接用，不用每次读都问；会改东西、发东西的操作每次都要用户确认。

### 阶段 1：读短信，以及统一的授权方式

- 设置里有一个「手机能力」列表，每种能力一行：说明它能让 Codex 做什么、现在开没开。默认全部关闭。
- 打开某项能力时，用一两句话说清楚：Codex 能读到什么；读到的内容会发给模型处理；随时可以在这里关掉。需要 Android 系统授权的，在这时向系统申请；用户拒绝了，就保持关闭，并告诉用户怎么去系统设置里补开。
- 第一项能力是读短信：Codex 能按时间、发件人、关键词找短信并读出内容，例如找最近的验证码、汇总某个号码发来的短信、找含某个词的短信。
- 能力没开时，用户在对话里提出相关要求，Codex 不假装做到，而是说清楚要开哪项能力、在哪里开；开了以后在同一段对话里继续就能用。
- 对话里能看出 Codex 用了哪项手机能力、大概读了什么（比如「读取了 3 条短信」），点开能看到具体内容。
- 现有的读系统设置、改亮度并入这个列表，作为其中两项能力，用法和其他能力一致。

### 阶段 2：更多只读能力

在同一个列表里加上下面几项，规则和阶段 1 一样：

- 通讯录：按名字、号码找联系人，例如「张三的电话是多少」，也能把短信里的号码对上联系人名字。
- 通话记录：最近的来电、去电、未接电话。
- 日历：查某段时间的日程。
- 手机里的照片和文件：能找到并读取相册、下载、文档等手机共享目录里的文件，例如「把下载里最新的 PDF 总结一下」。新建 Codex 对话选工作目录时（见 2026-11-20-01），这些共享目录也能选。

### 阶段 3：会改东西的操作

- 发短信、新建或修改日程、新建联系人、把文件保存到手机共享目录。
- 每次操作前都弹确认，写清楚到底要做什么：发短信要显示收件人和完整内容，日程要显示时间和标题，保存文件要显示位置和文件名。用户拒绝后 Codex 不重试、不换别的办法绕过去。
- 一次确认只对应一次操作；Codex 想连发几条短信，要一条一条确认。
- 做完后在对话里说明结果，做没做成以实际结果为准。

## 不做

- 桌面端的任何改动。
- 终端里直接运行的 `codex` 用这些能力（这次只在 Waddle 的 Codex 对话里）。
- 读其他应用的通知、读别的应用的界面内容、代替用户点屏幕。
- 拨打电话、删除短信 / 联系人 / 日程 / 文件。
- 后台自动执行：没有用户在对话里提出，Codex 不主动去读短信或其他内容。
- 上架应用商店需要满足的额外要求。

## 怎样算做好

### 阶段 1

- 在安卓模拟器和 Fold7 上，设置里能看到「手机能力」列表，默认都关；打开读短信时有说明并弹系统授权，拒绝授权后仍是关闭，并能看到怎么补开。
- 读短信关着时让 Codex 找验证码，它说明需要开哪项能力、在哪开；打开后在同一段对话里再问，能答对。
- 模拟器里发几条测试短信（不同发件人、含验证码、含关键词），让 Codex 找最近的验证码、汇总某个号码的短信、找含某个词的短信，结果和手机短信应用里看到的一致；Fold7 上用真实短信试一次找验证码。
- 对话里能看到这次读了几条短信，点开能看到内容；关掉这项能力后，Codex 立刻读不到了。
- 读系统设置、改亮度仍然能用，在「手机能力」列表里能找到，改亮度每次照样要确认。
- 更新安装后用户文件和 Codex 登录保留；Android 构建和现有设备测试通过；桌面端照常能构建和测试。

### 阶段 2

- 通讯录、通话记录、日历、照片和文件四项能力都出现在列表里，开关和授权方式与短信一致。
- 在模拟器里放一些测试联系人、通话记录、日程、下载目录里的文件，让 Codex 分别查找，结果正确；把短信里的号码对上联系人名字能做到。
- 新建 Codex 对话时能选手机的下载、文档等共享目录作为工作目录，在里面读文件正常。
- 关掉某一项后，Codex 对应的内容读不到了，其他项不受影响。
- Android 构建和现有设备测试通过；桌面端照常能构建和测试。

### 阶段 3

- 在模拟器上让 Codex 给一个号码发短信：确认框里收件人和内容与最终发出的一致；拒绝后没有发出，Codex 不再尝试。
- 让 Codex 连发两条短信，要确认两次；只确认第一条时只发出第一条。
- 新建日程、新建联系人、保存文件到下载目录，确认框写清楚要做的事，做完后在手机对应应用里能看到。
- 对应能力关着时，这些操作都做不了，Codex 说清楚原因。
- Android 构建和现有设备测试通过；桌面端照常能构建和测试。
