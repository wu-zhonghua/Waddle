# Android 界面规范

适用于 Waddle Android 终端、对话、文件、设置和所有临时面板。深色主题，Compose 的 `WaddleTheme` 为唯一主题入口。

## 颜色

| 用途 | 色值 | 规则 |
|---|---|---|
| 工作区 | `#101216` | 终端与页面背景 |
| 表面 | `#181B21` | 导航、工具栏、代码区 |
| 分隔线 | `#30343D` | 列表边界、输入边框 |
| 正文 | `#E6E8ED` | 正文、普通操作、线性图标 |
| 次要信息 | `#9DA3AF` | 路径、时间、状态 |
| 强调 | `#8BAAFF` | 当前选中项、一个主要操作、焦点 |
| 错误/删除 | `#F1A5A5` | 只表示失败和 diff 删除，不作装饰 |

不使用渐变、发光或星星。增加行用强调色与 `+`，删除行用错误色与 `-`，不能只靠颜色表达变化。终端用户程序的 ANSI 颜色保持原样。

## 排版与间距

使用系统无衬线；命令、输出、路径和 diff 使用等宽。页面标题 20sp，工具栏标题 16sp，正文 14sp，元数据 12sp。所有字号随系统字体缩放；不可用固定高度截断正文。

以 4dp 为间距单位：行内 8dp，内容 16dp，分组 24dp。操作目标至少 48dp。圆角：输入/按钮 8dp，菜单/决策弹窗 12dp；消息与文件列表不用卡片。普通文本按钮保持正文色；主要动作使用实心强调色按钮。危险动作写清结果，保留取消/拒绝。

## 图标

使用 `WaddleIcon` 的一套 24dp、1.8dp 描边线性图标，不混用 emoji、填充文件夹或字符装饰。图标按钮必须有中文无障碍名称；文字动作也保留原有可发现性。

## 布局

- 终端：56dp 顶部栏，名称与短路径；终端占剩余空间，底部低调 AI 入口及 48dp 快捷键栏。无 RUNNING/Bash 品牌尾栏。
- 导航：文件在顶部，终端和对话共用两行列表（图标、名称、短路径/状态），设置与帮助在底部。名称采用目录名，重复会话用序号区分。
- 屏幕宽度达到 840dp 时左侧常驻 256dp 导航；更窄时使用抽屉。布局变化不替换服务持有的终端或对话；对话草稿由服务持有，文件视图偏好使用可保存状态。
- 对话：普通消息平铺，命令有等宽输出区，文件变更按行显示 diff；审批使用明确的允许与拒绝。无账号时展示用途和登录主操作，保留历史、账号、返回与结束入口。
- 文件：默认紧凑列表，支持网格，文件夹操作紧邻条目；目录打开终端保持显眼，但不占整行。云来源复制与权限说明仍保留，因为会影响用户决定。
- 设置、账号、模型、帮助使用全屏页面；弹窗只用于选择、确认、授权说明或错误。账号逐服务显示状态和配置入口。
- 问 AI/看报错：输入、模型、生成是主体；上下文检查及账号入口使用带标签的次要操作。保留上下文检查和生成后的可编辑确认，不隐藏影响发送/执行的决定。

## 路径和文案

应用家目录只显示 `~`、`~/demo`。完整路径保留在「查看完整路径」或可编辑的路径输入中；外部存储不能假装是私有目录。标题下不放解释性副标题。状态用「运行中」「已退出」「等待确认」等自然语言；不暴露内部连接实现。保留数据传输、文件复制、关闭会话等决定所需的说明。
