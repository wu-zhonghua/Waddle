# Waddle 官网首页：先搭好框架，样子跟着 App 的设计走

- 状态：待实现
- 日期：2026-11-23
- 上一份：无（在 [2026-11-23-02-product-ui-redesign](2026-11-23-02-product-ui-redesign.md) 之后做，视觉沿用它定下的设计规范）
- 涉及：官网（新增）；安卓、桌面端不改

## 现在的样子

Waddle 还没有自己的官网。仓库里只有桌面端从上游带过来的文档站（`apps/desktop/docs`，有自己的发布流程），讲的是桌面端，跟现在的「手机上的 AI 终端」不是一回事。

安卓界面刚按 [android-design-system.md](android-design-system.md) 重做过，去掉了渐变、发光、星星和一排排一样的圆角卡片。改后的截图在 `docs/dev/screenshots/2026-11-23-02-after-*.png`。

## 要做什么

做一个 Waddle 官网首页的**框架**：页面结构、各部分的位置和样式先定下来，文案和图片可以先用占位，以后逐步填实。官网是一个独立的部分，和安卓、桌面端分开放、分开构建，例如放在 `apps/website/`。

**首页分这几部分：**

1. **顶部**：Waddle 名字、语言切换（English / 中文）、GitHub 链接。
2. **开头（hero）**：一句话说清 Waddle 是什么，例如「手机上的 AI 终端」；配一张 App 的真实截图（先用终端页或 Codex 对话页）；一个主要按钮，指向下载部分。
3. **功能**：讲清这几件事，每件配一张 App 截图或一段终端内容：
   - 真正的终端：本地 Bash、多会话、文件、快捷键栏。
   - 内置 AI 写命令、看报错：DeepSeek、通义千问、Kimi、智谱、OpenAI 兼容；生成的命令先确认再运行。
   - 安装包自带 Codex，在终端里敲 `codex` 就能用（以后还有 Claude Code、Antigravity）。
   - 一个「账号」页管好所有登录和 Key。
   - 适配折叠屏：展开时左侧常驻导航（用 unfolded 截图）。
4. **下载**：安卓、桌面端（macOS / Windows / Linux）的位置。现在还没有公开发布，所以都显示「即将推出 / Coming soon」，**不放会让人以为能下载的假链接**。
5. **底部**：南溟科技（Nanming Tech）出品、GitHub、许可（安卓 GPL-3.0、桌面 Apache-2.0）。

**语言：** 默认英文，页面上可以切到中文，切换后整页文字都换成中文。两种语言的文案放在一起维护，改了一种容易看出另一种也要改。

**样子：跟 App 是一套设计。** 用户看完官网再打开 App，应该觉得是同一个产品：

- 颜色、字体（无衬线 + 命令/路径/输出用等宽）、字号层级、4 的倍数间距、圆角、线性图标，都照 [android-design-system.md](android-design-system.md)。深色，背景和 App 工作区一样。
- 这些颜色、字号、间距在官网里**只定义一处**，并注明对应规范里的哪一项。以后 App 规范改了，官网改一处就能全部跟上。
- **不能看起来像 AI 生成的页面**：不用渐变、发光、星星图标、emoji；功能部分不是「一排一样大的卡片、每张卡片一个圆圈图标加一句话」，而是截图和文字左右交替或类似的、有主次的排法；不在每个标题下面加一句解释性副标题。强调色只用在一个主要操作和当前选中项上。

**国内版：** 和 App 一样，同一份官网源码能出一个国内版页面，不出现 Codex、Claude Code、Antigravity 和其他海外服务，只讲终端和国内模型。现在默认出的是国际版，国内版只要能生成、能看，不对外。

**以后跟着 App 改：** 官网目录里写一份简短说明：怎么在本地打开预览；颜色/字号从哪里来、App 规范改了要改哪里；截图从哪里来、怎么换成新截图。

## 不做

- **不部署、不发布到任何公网地址**（GitHub Pages、域名、CDN 等都不做），也不加推到 `main` 就会自动发布官网的工作流。上线另外问用户。
- 不改桌面端文档站（`apps/desktop/docs` 及其发布流程），不改安卓和桌面端的代码与 CI。
- 不写正式文案和营销内容，不做博客、文档、价格、登录、统计分析、Cookie 弹窗。
- 不做真实下载链接、二维码。
- 不做浅色主题。

## 怎样算做好

在 macOS 上用浏览器打开本地预览检查：

- 首页从上到下有顶部、开头、功能、下载、底部五部分；默认英文，切到中文后整页文字都是中文，再切回英文也正常。
- 和 App 改后截图放在一起看是同一套设计：颜色、字号、等宽字体用法、间距、图标风格一致；页面上没有渐变、发光、星星、emoji，功能部分不是一排一样的圆圈图标卡片。所有截图都是 App 的真实截图。
- 手机宽度（约 375px）和电脑宽度（1280px 以上）都排得好，没有横向滚动条，图片不变形、不糊。
- 下载部分清楚说明还没发布，没有点了会 404 或下载到别的东西的链接；GitHub 链接指向 `wu-zhonghua/Waddle`。
- 能按说明生成国内版页面，里面找不到 Codex、Claude Code、Antigravity 这些字样。
- 官网目录里的说明写清了怎么预览、App 设计改了以后要改哪里；安卓、桌面端的构建和 GitHub 上已有的检查不受影响，没有新增任何发布到公网的动作。
