# 找到文件夹，在这个文件夹直接打开终端

- 状态：验收不通过
- 日期：2026-11-21
- 上一份：[2026-11-21-01-files-drawer](2026-11-21-01-files-drawer.md)、[2026-11-20-03-file-browser](2026-11-20-03-file-browser.md)
- 涉及：安卓

## 现在的样子

用户验收后指出：需要的是找到一个文件夹并在这里工作，而不是先浏览文件、再辨认「在终端打开 / 新终端 / 交给 Codex」这排按钮。目前文件夹卡片本身没有直接打开终端的操作；底部默认按钮还会切换已有终端的目录，和用户期望的新开终端不一致。

## 要做什么

- 保留点文件夹图标/名称进入浏览。每个文件夹旁边明确提供「在此打开终端」，不用先进入该文件夹再找其他页面的按钮。
- 当前浏览目录底部同样提供明显的「在此打开终端」，显示它将打开的文件夹和路径，说明会新开终端、保留旧会话。原来切换当前终端、交给 Codex 的能力放到次要菜单，不与主操作混排。
- 点击后直接切到新终端；它启动时的工作目录就是所选文件夹。提示符/标题能看出所在目录，`pwd`、`ls` 和创建文件均作用于该目录，不用再手动 `cd`。中文、空格、引号等合法目录名正常工作。
- 不改变原来终端的目录、输出和运行任务。目录失效、没有访问权限或会话达到上限时留在文件页显示原因，不静默换目录、不停止其他会话。
- 只对 Waddle 可直接访问的普通目录提供原地打开。系统文件提供方的目录不能冒充 Bash 路径：明确标注「导入副本…」，解释原件与副本，用户确认后才导入；完成后能明确在副本目录打开终端。取消不导入、不新建会话。
- 保留现有用户文件、授权和 Codex 登录，不新增存储权限。

## 不做

- 不实现通用共享目录挂载、手机原件自动写回、整机文件管理权限。
- 不实现完整项目管理或改变 Codex 对话工作目录，也不把这些能力标记为完成；本轮完成用户进一步确认的「文件夹 → 在此打开终端」流程。
- 不改桌面端，不在用户正在验收的真机上自动测试或重启；先在独立模拟器验证并提供验收包。

## 怎样算做好

- 模拟器里点一个尚未进入的文件夹旁的按钮，新终端直接启动在该子目录；从已进入目录底部打开同样正确，成功后显示终端页。
- 在含中文、空格和单引号的目录执行 `pwd`、`ls`、写测试文件，路径和内容正确；不会向原会话输入命令，原会话可继续运行。
- 浏览/打开更多菜单不执行命令。旧的切换当前终端功能仍可从菜单访问，并保持前台程序保护。
- 已删除目录和 8 个会话上限显示错误，不额外创建会话。共享目录的入口标明副本，取消确认后原文件、会话和导入状态不变。
- 构建、Lint、相关导航/文件/终端设备回归通过；记录实现说明与测试平台，交验收者验收。

## 实现说明（实现者填写）

已实现，等待验收。本轮实现用户进一步明确的「找到文件夹 → 在此打开终端」，不将完整项目工作区或 Codex cwd 能力标记为完成。

### 怎么用

1. 左侧文件夹入口进入浏览页。点文件夹图标/名称仍是进入浏览；点该卡片下方「在此打开终端」，直接新开一个从这个文件夹启动的 Bash，并切到终端页。
2. 已进入目录时，底部显示「在 <文件夹> 中工作」、目标路径和同名主按钮，明确提示新开终端、旧会话保留。原来的三按钮并排已移除。
3. 终端标题显示 `Shell N · 文件夹名`，下一行和提示符显示当前路径；直接执行 `pwd`、`ls` 或创建文件即可，不用再 cd。
4. 「更多 → 切换当前终端到此目录」保留原来的受保护 cd；「更多 → 交给 Codex」保留选择本地路径的能力，不自动发送。
5. 系统授权的共享目录卡片显示「导入副本…」。点击后解释不能直接作为终端目录、修改不会写回原件；取消不会导入。确认后沿用原有导入流程，完成结果中提供「在副本中打开终端」，目标是明确显示的 Imports 本地目录。

### 实现

- `ui/FileBrowserScreen.kt`：将卡片的浏览和开终端分为独立点击区域；普通目录使用既有 `TerminalWorkspace.create(directory)`，不向原 Shell 输入 cd，也不要求旧会话先停止。底部使用一个明确的主按钮，次要操作收进菜单；共享目录增加副本说明确认与导入完成后的终端入口。
- `ui/WaddleScreen.kt`：终端标题附加当前目录名，帮助文字同步更新。`TerminalScreen.kt` 在 AndroidView 挂载后获取焦点，避免新终端尚未挂载时的焦点请求无效，导致回车作用到导航按钮。
- `terminal/TerminalWorkspace.kt`：在创建入口统一执行 8 个会话上限检查；目录合法性/可读可进入检查仍在创建会话前完成。失败不新增会话、不改变当前选中项。
- 未更改登录、权限、原生终端组件、导入数据格式、Codex 运行时或桌面端。
