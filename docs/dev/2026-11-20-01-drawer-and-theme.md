# 安卓端改用左侧抽屉切换终端和 Codex（可选工作目录），并能选浅色/深色主题（2 个阶段）

- 状态：待实现（阶段 1）
- 日期：2026-11-20
- 上一份：无（基于 2026-11-19-01、2026-11-19-02 已实现能力）
- 涉及：安卓

## 现在的样子

打开 Waddle，最上面一行是「终端 / Codex」两个文字按钮并排，右边一个「Waddle」；点「终端」后下面又有一整块 Waddle 标题栏和一行终端会话标签，等于两层标题叠在一起，看着乱，也占地方。Codex 只有一个固定页面，同一时间只有一段对话，看不出它和终端会话是什么关系。Codex 页的工作目录固定是 `~`，用户没法换。

Codex 页主界面上摆着「读取设置」「允许修改亮度」开关、「系统授权」按钮，以及「读取亮度和飞行模式」「将亮度设为 128…」两个快捷按钮。这些是上一份需求为了验证能读写系统设置加的测试入口，放在主界面上让 Codex 看起来像个调亮度的工具。Waddle 里的 Codex 是通用的：用户让它干什么就干什么，读写手机能力只是其中一种。

整个应用只有黑绿配色，状态栏、终端区域、Codex 页、弹窗都是深色，没有地方可以换。

## 要做什么

### 阶段 1：左侧抽屉，Codex 也是一种会话

用户在手机上同时开着几个终端和 Codex 对话，希望像常见聊天/终端应用那样：主界面只放当前正在用的那一个，其他的收在左边。

- 顶部只留一行标题栏，左边是「☰」按钮。点它（或从屏幕左边缘往右滑）拉出左侧抽屉。
- 抽屉里列出所有打开的会话：终端会话和 Codex 对话放在一起，一眼能分清哪个是终端、哪个是 Codex，能看出哪个正在运行、哪个是当前这个。点一个就切过去，抽屉收起。
- 抽屉里能新建会话，新建时选「终端」还是「Codex」。可以同时开多个 Codex 对话，各自独立；切到别的会话时，正在跑的 Codex 任务继续跑，切回来能看到结果和待审批的请求。
- 新建 Codex 对话时，用户选它的工作目录：可以直接用当前终端会话所在的目录，也可以选别的目录（终端里能进去的目录都能选），默认 `~`。Codex 读写文件、跑命令都从这个目录开始。当前对话的标题栏和抽屉里都能看到它的工作目录；继续以前的对话时，回到那段对话原来的目录。选的目录不存在或进不去时，说清原因，不会悄悄换成别的目录。
- Codex 对话页就是一个通用的对话界面：消息、输入框、停止、审批。主界面上不再放读取设置、修改亮度这类测试用的开关和快捷按钮。读写手机能力照样能用（用户在对话里提出时 Codex 去做，需要确认的照样确认），相关开关和系统授权放进设置里，用通用的说法，不在主界面上突出某一项具体能力。
- 抽屉里能关闭会话；关闭正在运行的会话前要确认。
- 以前能做到的照样能做到：继续上次的 Codex 对话、Codex 设置和运行环境说明、终端里「✦ 问 Codex，写命令」、帮助说明。它们的入口放在合适的地方，用户找得到。
- 主界面每种会话只显示一层标题：当前会话的名字（以及终端的当前路径、Codex 的连接状态），不再出现两层 Waddle 标题。

### 阶段 2：主题

用户觉得纯黑不好看，想换成浅色或跟着手机走。

- 在设置里（抽屉里或标题栏能进去）选主题：跟随系统、浅色、深色。默认跟随系统。
- 选完立刻生效，退出重开应用、手机重启后还是这个选择。
- 整个应用都跟着换：标题栏、抽屉、终端区域（背景、文字、光标、选中、底部按键栏）、Codex 页、命令建议抽屉、各种弹窗、状态栏和导航栏图标（浅色下图标要是深色，看得见）。
- 浅色下终端里的彩色输出仍然看得清：`ls` 的彩色文件名、`git` 的红绿差异、在终端里直接运行 `codex` 的界面，文字都不会因为颜色太浅而看不见。
- 跟随系统时，手机切换深浅色模式，Waddle 跟着变，正在运行的终端和 Codex 任务不中断、内容不丢。

## 不做

- 桌面端的任何改动。
- 自定义配色、导入主题文件、调字体（字号沿用现在的双指缩放）。
- 多个 Codex 对话之间共享上下文，或一个 Codex 对话直接操作某个终端会话。
- 平板/折叠屏展开时的左右分栏布局（展开时也用抽屉即可，能正常用就行）。
- 更换 Codex 版本、登录方式或权限范围。
- 新的手机能力（比如读短信、通讯录、相册），以及访问手机共享存储里的目录；这些另提需求。
- 一个 Codex 对话进行中途换工作目录。

## 怎样算做好

### 阶段 1

- 在安卓模拟器和 Fold7 上，打开应用只看到一行标题栏；点「☰」或从左边缘右滑能打开抽屉，点空白处或返回键能收起。
- 抽屉里新建 2 个终端和 2 个 Codex 对话，能分清类型、运行状态和当前项；来回切换时，终端内容、Codex 对话内容、正在进行的 Codex 任务和待审批请求都还在，不会串到别的会话。
- 新建 Codex 对话能选工作目录：选「当前终端目录」时，先在终端 `cd` 到一个含空格或中文的目录，Codex 里 `pwd` 和读写文件都在那个目录；选别的目录同样生效；标题栏和抽屉里显示的目录正确；继续以前的对话回到原目录；选不存在的目录时有看得懂的提示。
- Codex 对话主界面上没有亮度、飞行模式之类的测试开关和快捷按钮；在对话里让 Codex 读手机设置、改亮度仍然能做到，改动前照样要确认，相关授权能在设置里找到。
- 关闭一个会话只影响它自己；关闭运行中的会话前有确认。
- 以前的功能都还找得到并能用：继续上次 Codex 对话、Codex 设置与运行环境、终端「问 Codex 写命令」、帮助、终端底部按键栏、粘贴确认；旋转屏幕或切到后台再回来，打开的会话都还在。
- 更新安装后，用户文件和 Codex 登录保留；Android 构建和现有设备测试通过；桌面端照常能构建和测试。

### 阶段 2

- 在模拟器和 Fold7 上，设置里能选跟随系统 / 浅色 / 深色，立即生效；杀掉应用重开后选择还在。
- 浅色下截图检查：标题栏、抽屉、终端、Codex 页、命令建议抽屉、弹窗都是浅色，状态栏和导航栏图标看得见，没有残留的大块黑色区域。
- 浅色下终端里跑 `ls --color`、`git diff`、直接运行 `codex`，文字都能看清。
- 选「跟随系统」时切换手机深浅色模式，Waddle 跟着变，正在跑的终端命令和 Codex 任务不中断。
- 深色主题和现在一样好用；Android 构建和现有设备测试通过；桌面端照常能构建和测试。
