# 扩展：Codex、Claude Code 等工具按需下载安装（2 个阶段）

- 状态：已取消（2026-11-22 方向改了，由 [2026-11-22-04](2026-11-22-04-bundled-agents-and-accounts.md) 取代）
- 日期：2026-11-22
- 上一份：无（在 2026-11-22-01 阶段 1 之后做）
- 涉及：安卓

## 现在的样子

按 2026-11-22-01，Waddle 本体不带 Codex，终端里的 AI 用的是用户自己配的模型（DeepSeek 等）。有的用户还想用 Codex、Claude Code 这类更强的 AI 编程工具，现在 Waddle 里没地方装。

## 要做什么

把这类工具做成**扩展**：想用的人自己下载安装，不装的人完全看不到、也不占空间。Waddle 本体仍然是 AI 终端，扩展只是加选项。

### 阶段 1：扩展页面和 Codex 扩展

1. **扩展页面：**抽屉和设置里都能进“扩展”页面。
   - 每个可装的工具都写清楚：名称、一句话简介、大小、来源和许可、要用什么账号，再加一个“安装”按钮。
   - 已经装好的显示版本，可以更新、可以卸载。
2. **安装：**点“安装”就开始装。安装方式要符合安卓系统和应用商店的规定。如果中途要跳到系统安装界面或应用商店，先告诉用户为什么，装完能回到 Waddle。
3. **装好 Codex 以后：**
   - 终端里能直接敲 `codex`。
   - 抽屉里出现 Codex 对话入口，文件夹菜单里出现“在这里打开 Codex”。
   - 登录一次，终端和对话两边都能用。
4. **没装的时候：**终端里敲 `codex`，提示还没安装，并给一个“去安装”的入口。
5. **卸载：**卸载以后这些入口都消失，Waddle 本体、用户文件、内置 AI 都不受影响。
6. **国内版和国际版：**国内渠道的安装包里，扩展页面不显示 Codex、Claude Code 这类海外工具；国际渠道的显示。

### 阶段 2：Claude Code 扩展

1. 用同样的方式安装 Claude Code。装好后终端里能直接敲 `claude`，抽屉里出现 Claude 对话入口，文件夹菜单里出现“在这里打开 Claude”。
2. Claude 要执行命令、改文件之前，用户能看到它要做什么，可以同意或拒绝。
3. Codex 和 Claude Code 可以同时装、同时用，两边的对话和登录互不影响。

## 不做

- 桌面端的扩展。
- 让第三方开发者上传扩展，或者做扩展市场。
- Waddle 代用户开通、购买这些工具的账号。
- DeepSeek 等模型做成扩展（它们走 2026-11-22-01 的内置 AI）。

## 怎样算做好

### 阶段 1

- 在安卓模拟器和 Fold7 上，扩展页面能看到 Codex 的介绍和安装按钮。从点“安装”到装好，步骤少，每一步用户都看得懂。
- 装好后，终端里 `codex` 能用，Codex 对话入口和“在这里打开 Codex”都出现了。登录一次两边都能用。在真机上用真实模型完成一个读文件、写文件的小任务。
- 没装时敲 `codex`，有提示和安装入口。卸载后入口都消失，用户文件、终端、内置 AI 不受影响；再装回来又能用。
- 国内渠道的包里看不到 Codex 和 Claude Code，国际渠道的包里能看到。
- 2026-11-22-01 的内置 AI 功能照常能用。GitHub 上的 Android 和 Desktop checks 都通过，桌面端照常能用。

### 阶段 2

- 在模拟器和 Fold7 上，从扩展页面装好 Claude Code 后，终端里 `claude` 能用，Claude 对话入口和“在这里打开 Claude”都出现了。在真机上用真实模型完成一个读文件、写文件的小任务。
- Claude 要执行命令、改文件时会先问用户，用户拒绝的就不执行。
- Codex 和 Claude Code 同时装好，各开一个对话同时用，内容不会串。卸载其中一个，另一个照常能用。
- GitHub 上的 Android 和 Desktop checks 都通过。
