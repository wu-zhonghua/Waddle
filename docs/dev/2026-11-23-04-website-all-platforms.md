# 官网改成全平台：macOS、Windows、Linux 和安卓手机都能用的 AI 终端

- 状态：验收通过
- 日期：2026-11-23
- 上一份：无（扩展 [2026-11-23-03-website-framework](2026-11-23-03-website-framework.md)，03 已验收通过）
- 涉及：官网；安卓、桌面端不改

## 现在的样子

03 做好的官网框架只讲手机，内容是这样的：

- 开头一句是「An AI terminal on your phone」。
- 五项功能全是安卓的。
- 桌面端只在下载区出现。

可 Waddle 本来就是电脑和手机都能用的：

- 桌面端（macOS、Windows、Linux）已经有了：
  - 内置 AI 助手，能读终端输出，支持多家模型和本地模型。
  - 断线不掉的 SSH 会话。
  - 远程文件编辑和预览。
  - 可以拖拽排布的终端、编辑器、浏览器区块。
- 安卓有本地 Bash、内置 AI 写命令、自带 Codex、统一账号页和折叠屏布局。

用户第一眼看官网，会以为 Waddle 只是个手机 App。

## 要做什么

把官网改成讲**一个跨平台的 AI 终端**：电脑上和手机上都能用，各有所长。页面框架、设计规范、双语、国内版这些 03 定下的都保留，只改内容和排法。

**开头：**

- 一句话说清 Waddle 是 macOS、Windows、Linux 和安卓上的 AI 终端。
- 同时放一张电脑截图和一张手机截图。
- 写明支持哪些平台。

**功能：**

- 能看出每项功能在哪些平台上有，做法自定。可以分「电脑上」「手机上」两部分，也可以每项功能标出平台。
- **电脑**这边讲桌面端已有的主要能力：
  - AI 助手（读终端输出、多家模型、本地模型）
  - 断线不掉的 SSH
  - 远程文件编辑和预览
  - 区块布局
- **手机**这边保留 03 的内容：
  - 本地终端
  - 内置 AI 写命令、看报错
  - 自带 Codex
  - 账号页
  - 折叠屏
- 只写在桌面端或安卓上**实际跑起来确认过**的功能。上游 README 里写的、Waddle 现在不一定有的东西不要写，比如「Free Beta AI credits」、上游的文档站链接。

**截图：**

- 桌面端还没有截图，要在 Mac 上把桌面端真正跑起来，截主要界面。
- 截图里不能有真实账号、Key、私人文件、真实服务器地址。
- 两种版本的截图都要原样记下来源，和 03 的手机截图一样。

**下载：** 四个平台照旧显示「即将推出」，不放假链接。

**国内版：**

- 国内版页面也要讲电脑和手机。
- 页面里和截图里都不出现海外 AI 产品和服务名，例如 Codex、Claude、Gemini、Antigravity、ChatGPT、OpenAI。
- 讲桌面端 AI 时，只说支持哪类模型，例如国内模型、本地模型、自定义兼容地址。

**说明文档：** 官网目录里的说明补上桌面端截图从哪里来、怎么重新截。以后桌面端外观改了，官网也要跟着换截图。

## 不做

- 不改桌面端和安卓的界面，也不改它们的代码。桌面端的外观还没按 [android-design-system.md](android-design-system.md) 重做，所以电脑截图和手机截图风格会不一样；这次先接受，桌面端重做另提需求。
- 不加 iOS。页面上也不写会出 iOS 版。
- 不部署、不发布到任何公网地址，不加会自动发布的工作流。
- 不改 03 已定的页面视觉规则：不用渐变、发光、星星、emoji，也不排一排一样的圆圈图标卡片。

## 怎样算做好

在 macOS 上用浏览器打开本地预览检查：

- 只看开头一屏（手机宽度和电脑宽度都算），就能知道 Waddle 在 macOS、Windows、Linux 和安卓上都能用，并且同时看到电脑和手机的真实截图。
- 功能部分讲了电脑和手机两边的能力，能看出每项在哪些平台上有；写的功能都在实际运行的桌面端或安卓上能找到。
- 中英文切换、手机宽度（约 375px）和电脑宽度（1280px 以上）都像 03 一样正常：没有横向滚动，图片不变形。
- 国内版页面也讲了电脑和手机，正文和截图里找不到 Codex、Claude、Gemini、Antigravity、ChatGPT、OpenAI。
- 下载部分四个平台都是「即将推出」，没有假链接。没有新增任何发布到公网的动作，安卓和桌面端的代码与检查不受影响。

## 实现说明（实现者填写）

### 做了什么

- 仅改 `apps/website/`、本节/本文件状态，以及需求索引的 2026-11-23-04 行。未修改安卓、桌面端被跟踪文件、其他需求、设计规范或既有截图；未提交、建分支、stash、推送或部署，未改任何工作流。
- 中英文、国际/国内四份页面都以跨平台 AI 终端介绍 Waddle。首屏列出 macOS、Windows、Linux、安卓，并同时显示桌面和手机真实截图；桌面截图加大、图注合并，窄屏仍在首屏内看到两端。
- 功能按「在电脑上」「在手机上」分组，增加页内跳转。电脑展示 AI 终端上下文、多模型/本地/自定义地址、带前提的 SSH 持久会话、远程文件与区块布局；手机保留本地 Bash、AI 命令/报错、国际版自带工具、账号与折叠布局。四个平台下载仍全为「即将推出」，没有假链接。
- 按用户追加要求搜索并阅读 [Warp Terminal](https://www.warp.dev/terminal)、[Wave Terminal](https://www.waveterm.dev/)、[Termius](https://termius.com/) 官方产品页，对照其产品定位、平台说明与按任务介绍能力的信息层次后调整首屏和分组。没有复制竞品图片、功能承诺或上游营销内容；参考取舍已写进官网 README。保留 03 的颜色、字号、间距、图标和圆角，没有渐变、发光或新增装饰卡片。
- 新增 `desktop-workspace.png`、`desktop-ai.png`：在 Mac 上从当前桌面源码运行 Waddle 0.14.16 / Electron 41.1.0，经本机 CDP 获取 2560×1520 原图，未裁剪、重绘或修图。临时配置、`demo $` 提示符、`Local` 连接名与专门生成的演示文件避免个人数据入镜。两版共用经过目视审查的桌面图，国内页面和全部国内图片不含需求所列海外 AI 名称。
- `assets/screenshots.json` 记录桌面来源、捕获方式、尺寸、SHA-256 和两版审查结论；安卓图的原始来源和文件保持不变。官网 README 增补完整重拍方法，并提供独立的演示配置/本地响应服务与原图捕获脚本，均不进入官网构建产物。

### 怎么试用

在仓库根目录执行：

```sh
cd apps/website
npm run preview             # http://127.0.0.1:4173，默认英文
# 另一个终端：
npm run preview:domestic    # http://127.0.0.1:4174
```

顶部 English / 中文切换，点「在电脑上 / 在手机上」跳到对应功能，点截图查看原图，点主要按钮查看四个平台的待发布状态。两种预览只监听回环地址；修改后重启预览、刷新。若端口已有本项目预览，先构建后刷新即可，不要杀别人的进程。

```sh
npm run build
npm run build:domestic
npm test
```

桌面截图复现见 [官网 README](../../apps/website/README.md#桌面截图来源与重拍)，包括临时配置、真实程序启动、演示内容、原图捕获和更换清单；截图辅助脚本要求 Node.js 22+，官网构建仍要求 Node.js 20+。

- macOS 26.3.1 ARM64 / Node.js 25.9.0：两版构建成功，官网自动测试 **6/6** 通过；校验四平台首屏、双端图、图像尺寸/来源/哈希、链接/锚点、下载区无链接、国内产物文字和图片隔离、两版互不覆盖。

- 桌面实际运行：Bash 命令、Markdown 预览/编辑/保存、区块由左右拖为上下、AI 自定义回环地址的流式响应及 `term_get_scrollback` 返回演示终端内容均完成。AI 回答为截图脚本的确定性协议响应，图中明确注明，不是假称真实模型推理或付费账号结果。
- 现有桌面 `go test ./pkg/jobmanager ./pkg/remote/... ./pkg/wshrpc/wshremote` 最终通过，覆盖持久会话断连/重连流管理及远程文件逻辑。早期沙箱下 Go 标准库解析失败，放开运行权限后曾因并发编译出现磁盘空间不足，最终一轮各包成功；没有为此改源码或删其他人的文件。ARM64 实际运行所需二进制已构建；`task build:server:macos` 中额外的 Intel 构建遇到本机 Go 工具链标准库错误，未声称 Intel 构建通过。
- 安卓内容沿用 02 的真实截图与设备测试记录。本轮额外在 `Waddle_API_35 / emulator-5554` 的既有安装中打开本地终端，确认文件入口、Bash、快捷键和 AI 命令入口；没有替换 APK、修改安卓代码或操作真机。账号、生成与折叠的完整运行证据仍是 02 的记录。

- 没有触发 CI 或公网发布；没有把之前需求的本地/远端检查算作本次运行结果。工作区其他改动保持原样。
