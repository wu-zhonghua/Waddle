# 文件夹浏览与共享文件导入

- 状态：验收不通过
- 日期：2026-11-20
- 上一份：无（补充 2026-11-20-02 的共享文件部分，不改变其阶段安排）
- 涉及：安卓

## 现在的样子

Waddle 只能通过终端命令查看自己的文件。手机的共享存储、可移动存储和系统文件提供方没有图形入口，也没有让终端或 Codex 使用所选文件的导入流程。

## 要做什么

- 提供文件页面，以清晰的文件夹/文件图标展示内容。能点击进入文件夹、返回上一级，通过路径导航回到已浏览的层级，刷新和查看隐藏文件。
- 浏览 Waddle 工作目录和其他本应用可访问的普通路径；能将所选目录打开到当前终端，或在新终端打开。前台交互程序和失效目录不能被错误输入打断。
- 通过 Android 系统选择器选择手机文件或授权一个文件夹，浏览已授权文件夹及其子目录。保留可持久化的授权入口，支持移除；取消、权限失效、存储拔出等情况有明确提示。
- 文件可查看名称、类型、大小和适合预览的文本。支持将所选共享文件或文件夹导入 Waddle，保留原件、不覆盖既有文件，明确标注是本地副本。导入后的目录可在终端打开，文件/目录可交给 Codex；发送前能看到选中的本地路径。
- 导入有进度、可取消，大目录/大文件不会卡住界面；失败不留下看起来成功的残缺文件夹。
- 沿用现有 Codex 登录与用户文件，不申请整机文件管理权限，不自动扫描或上传手机资料。

## 不做

- 本轮不实现短信、通讯录、日历能力，不变更其他需求的状态。
- 不把系统选择器授权伪装成普通 Bash 路径；不自动双向同步或覆盖共享存储原件。
- 不读其他 App 的私有数据，不实现完整 Office/PDF 编辑器，不改桌面端。

## 怎样算做好

- 图形浏览能进入含中文、空格、引号的目录，路径导航和返回正确；空目录、权限不足、文件删除有合理状态。
- 当前终端/新终端能进入选中的普通目录；运行中的交互程序不会收到切目录命令。
- 系统文件选择、文件夹授权、子目录浏览和授权移除可用；用户取消不产生错误导入。
- 导入文件与多层目录内容正确，重复导入不覆盖，危险文件名不能越界，取消或失败清理临时产物；原文件不变。
- Codex 使用导入后的本地路径，未登录或忙碌时不丢失所选内容，不自动发送。
- Android 构建、相关设备测试及终端回归通过。实现说明记录具体测试平台和剩余限制；本轮不自动重启用户正在试用的真机。

## 实现说明（实现者填写）

已实现，等待验收。此次只完成本文件定义的图形浏览/共享文件导入，不将短信等手机能力或左侧会话抽屉需求标记为完成。没有提交或推送，没有操作或更新用户的真机。

### 使用

1. 顶部点「文件」。文件夹以金色文件夹图标和卡片展示，点击进入；用「上一级」或路径中的名字返回。支持刷新、显示隐藏文件、「我的工作区」和输入普通绝对路径/`~/目录`。
2. 「＋ 手机文件夹」打开 Android 系统目录选择器，用户确认授权后，该入口保留在文件页；可进入子目录。入口旁的 × 移除持久读取授权和入口，不删除手机文件或已有副本。
3. 「选择手机文件」可单选文档、照片或其他文件，包括不允许整目录授权位置中的可选文件。取消选择保持原状态。图片/PDF/Office 等不在本轮完整预览范围；文本预览上限 64 KiB，超出时明确提示。
4. 普通本机目录可「在终端打开」，会在当前 Bash 执行安全引用的 cd；终端忙碌时提示等待或打开新终端。「新终端」直接从该目录启动，最多仍为 8 个会话。
5. 共享文件/目录可「导入副本」。后台复制完成后放入 `~/Imports/导入-唯一编号/原名称`，重复导入使用不同目录，原件不变。显示进度，可取消。完成后可查看副本或交给 Codex。
6. 「交给 Codex」只选择本地文件/目录路径，页面明确显示「尚未发送」。即使尚未连接/登录或当前任务繁忙，选择仍保留；用户输入任务并点击发送后，路径才随任务交给既有 Codex 对话。发送前再次检查本地文件是否仍存在和可读。

### 实现

- `files/FileAccess.kt`：普通路径用文件 API，系统授权位置用 DocumentsContract/ContentResolver，不从 content URI 猜测磁盘路径。只读取用户主动选择的共享内容，不新增存储权限、不自动扫描手机资料。
- `files/FileBrowserController.kt`：浏览/预览/导入均在 IO dispatcher 执行；列表和预览结果按代次隔离，防止快速切换后显示旧结果；保存授权入口、报告失效权限、管理导入进度与取消。
- `ui/FileBrowserScreen.kt`：文件夹网格、可点击路径、授权/文件选择器、预览弹窗、终端和 Codex 操作入口。截图检查后修正了深色背景上的默认文字颜色，并让两个手机文件入口同时可见。
- `TerminalWorkspace` 新增可验证的启动目录和切目录方法，复用已有提示符/前台进程检查与原 Bash 执行通道。`CodexScreen` 在明确选择后显示本地路径，用户发送时将其作为 JSON 引用路径附加到任务文本；没有更换 Codex 版本或登录方式。
- 导入先写私有 staging，所有内容成功后才原子移动到 Imports。文件名校验拒绝越界/控制字符，检测重名及循环目录；单次限制 512 MiB、5,000 项、32 层。普通错误和取消会清理临时文件；还覆盖了原子发布后、协程返回前收到取消的清理窗口。
- Android 可能禁止整机存储根、Download 根、Android/data、Android/obb 的目录授权，这由系统选择器决定。用户可选允许的子目录或单文件。可移动存储/云端来源由系统文件提供方暴露，本轮没有实体 SD 卡/U 盘测试。
- 共享内容不是普通 Bash 工作目录。此版提供本地副本工作流，不支持挂载、原件写回、同步或修改现有 Codex 会话的 cwd；这些能力不能视为其他需求已完成。
- 网络文件提供方阻塞时，取消可能要等读取返回；若 Android 强杀进程，私有 staging 可能残留，但不会显示为已成功导入的工作目录。移除授权不会删除已导入副本。
