# 安装包里带上 Codex、Claude Code、Antigravity，设置里统一登录账号；国内版能一键去掉（3 个阶段）

- 日期：2026-11-22
- 上一份：[2026-11-22-01-ai-terminal](2026-11-22-01-ai-terminal.md)（阶段 1 验收不通过）；取代 2026-11-22-02、2026-11-22-03
- 涉及：安卓

## 现在的样子

2026-11-22-01 阶段 1 把 Codex 从安装包里去掉了，换成内置 AI（DeepSeek、通义千问、Kimi、智谱、自定义 OpenAI 兼容）。用户在 Fold7 上打开终端，敲 `codex` 只看到 `command not found`，原来的 Codex 对话、“在这里打开 Codex”也都没了。这不是用户要的：用户要的是**各种都能用**，不是用国内模型换掉 Codex。另外 01 的 GitHub Android 检查没过：构建时缺 Codex 包，全新模拟器上第一次打开时弹出的通知权限询问挡住了设备测试（见 01 的验收记录）。

## 要做什么

Waddle 是 AI 终端，**能用的 AI 都带上**：

- 安装包里直接带 Codex、Claude Code、Antigravity，装好就有，终端里能直接敲 `codex`、`claude`、`agy`。
- 01 做好的内置 AI（DeepSeek 等）保留。
- 设置里有一个统一的「账号」页，所有要登录或填 Key 的地方都在这里。

以后要出国内版，国内版里不带这些海外工具。所以这次就要做到**很容易拆掉**：同一份代码能出两种安装包，国际版带全部工具，国内版一个都不带，界面里也看不到它们。国内版这次不上架、不发布，只要能建出来、试过没问题。

（01 验收时用户定过“Codex 包不进仓库”，那是在“产品不带 Codex”的前提下定的。现在要带，仓库里放不放这些安装包由实现者定，但要满足下面“怎样算做好”里关于干净代码构建和 CI 的要求。）

### 阶段 1：Codex 回来，加上「账号」页，能出国内版，CI 通过

1. **Codex 回到安装包里：**
   - 终端里能直接敲 `codex`。
   - 抽屉里有 Codex 对话，可以开多个，每个有自己的工作目录。
   - 文件夹菜单里有“在这里打开 Codex”。
   - Codex 给的图片、文件路径照之前那样能直接看。
   - 0.4.0 时能用的这些，都要回来。
2. **「账号」页：**设置里新增，一处看到所有账号的状态（已登录 / 没登录 / Key 已保存）。
   - Codex：用 ChatGPT 账号登录，或者填 API Key。能退出登录。
   - 内置 AI：01 做好的 DeepSeek、通义千问、Kimi、智谱、自定义 Key 和模型设置，挪到这里或从这里能直接进去。
   - 在这里登录一次，终端里的 `codex` 和 Codex 对话都能用，不用登两次。
   - 从 0.4.0 或 0.5.0 覆盖安装，原来的 Codex 登录还在，不用重新登。
3. **写命令、看报错可以选用哪个 AI：**“问 AI，写命令”和“让 AI 看看”可以选用内置模型（DeepSeek 等），也可以选用已登录的 Codex。
4. **国内版：**同一份代码能建出国内版安装包。
   - 国内版里没有 Codex、Claude Code、Antigravity 这些程序，终端里敲这些命令都提示没有。
   - 「账号」页、抽屉、文件夹菜单里也看不到它们。
   - 内置 AI 和终端功能照常能用。
5. **第一次打开：**全新安装后第一次打开，会询问通知权限。不管选“允许”还是“不允许”，终端、文件浏览、AI 入口都能正常用。

### 阶段 2：Claude Code

1. 安装包里带 Claude Code，终端里能直接敲 `claude`。
2. 「账号」页里能登录 Claude 账号，或者填 Anthropic API Key；也能退出登录。
3. 抽屉里有 Claude 对话入口，文件夹菜单里有“在这里打开 Claude”。Claude 要执行命令、改文件之前，用户能看到它要做什么，可以同意或拒绝。
4. “写命令、看报错”也可以选用 Claude。
5. Codex 和 Claude 可以同时开、同时用，对话和登录互不影响。

### 阶段 3：Antigravity

1. 安装包里带 Antigravity 的命令行工具，终端里能直接敲 `agy`。
2. 「账号」页里能用 Google 账号登录，也能退出登录。
3. 抽屉里有 Antigravity 对话入口，文件夹菜单里有“在这里打开 Antigravity”。要执行命令、改文件之前，用户能看到它要做什么，可以同意或拒绝。
4. 如果确认 Antigravity 在安卓上跑不起来，在实现说明里写清楚原因和试过什么，然后停下等用户决定，不要硬做一个半能用的。

## 怎样算做好

### 阶段 1

- 在安卓模拟器和 Fold7 上（国际版）：
  - 终端里 `codex` 能打开；抽屉里能开多个 Codex 对话，每个有自己的工作目录；文件夹菜单里有“在这里打开 Codex”。
  - 在真机上用真实账号让 Codex 完成一个读文件、写文件的小任务。
- 「账号」页能看到 Codex 和内置 AI 的状态：
  - Codex 能登录、退出。
  - 登录一次，终端和对话都能用。
  - 在 Fold7 上从 0.5.0 覆盖安装，原来的 Codex 登录还在，用户文件不丢。
- “问 AI，写命令”和“让 AI 看看”能在内置模型和 Codex 之间切换；选 Codex 时能真实生成命令，确认后才执行。
- 国内版装到模拟器上：
  - 终端里 `codex` 提示没有这个命令。
  - 「账号」页、抽屉、文件夹菜单里看不到 Codex、Claude Code、Antigravity。
  - 终端和内置 AI 照常能用。
  - 国内版安装包明显比国际版小。
- 在全新模拟器上新装，第一次打开时的通知询问选“允许”或“不允许”，之后终端、文件浏览、AI 入口都正常。
- 从刚 clone 的干净代码能按 README 构建出国际版和国内版。构建不依赖随时可能消失的外部下载地址。GitHub 上的 Android（构建和设备测试）和 Desktop checks 都通过。

### 阶段 2

- 在模拟器和 Fold7 上，终端里 `claude` 能打开，Claude 对话入口和“在这里打开 Claude”都在。
- 「账号」页能登录、退出 Claude。在真机上用真实账号让 Claude 完成一个读文件、写文件的小任务。Claude 要执行的命令和改文件，用户拒绝的就不执行。
- “写命令、看报错”能选用 Claude。
- Codex 和 Claude 各开一个对话同时用，内容不会串；退出其中一个的登录，另一个不受影响。
- 国内版里仍然看不到 Claude。GitHub 上的 Android 和 Desktop checks 都通过。

### 阶段 3

- 在模拟器和 Fold7 上，终端里 `agy` 能打开，Antigravity 对话入口和“在这里打开 Antigravity”都在。
- 「账号」页能用 Google 账号登录、退出。在真机上用真实账号完成一个读文件、写文件的小任务。
- Codex、Claude、Antigravity 三个同时用，互不影响。
- 国内版里仍然看不到 Antigravity。GitHub 上的 Android 和 Desktop checks 都通过。
- 如果 Antigravity 在安卓上跑不起来：实现说明里有原因和试过的办法，前两个阶段的东西不受影响。
