# 文件作为左侧固定入口，接入统一导航抽屉

- 状态：验收不通过
- 日期：2026-11-21
- 上一份：[2026-11-20-03-file-browser](2026-11-20-03-file-browser.md)；补充 [2026-11-20-01-drawer-and-theme](2026-11-20-01-drawer-and-theme.md) 的导航基础，不替代其完整阶段验收
- 涉及：安卓

## 现在的样子

顶部是「终端 / Codex / 文件」，文件排在最后；终端内部还有标题和会话标签。文件浏览已能进入文件夹、导入共享文件副本并交给终端或 Codex，但入口与即将采用的左侧抽屉不一致。

## 要做什么

- 文件放在左侧：主界面左侧有明确的文件快捷入口；左侧抽屉中「文件」是第一个固定导航项，不与可关闭的会话混排。移除旧的三页横向标签，顶部只留一层当前页面/会话标题。
- 点击菜单按钮可打开左侧抽屉，也支持左侧滑出；点击遮罩或返回收起。手机及折叠屏当前阶段均使用可收起抽屉，不挤占终端宽度。
- 抽屉的会话分组展示现有终端会话及现有 Codex 入口，标出当前项、运行/连接状态；选中后收起抽屉。可新建终端、关闭终端，关闭前确认；设置与帮助入口固定在下方。保留 Codex 运行环境、连接、审批和停止等已有能力。
- 文件入口排第一不意味着每次启动都跳到文件页。首次进入仍是终端，Activity 重建和页间切换保留当前页、文件浏览位置、Codex 草稿及尚未发送的所选文件；回到终端不重建 Shell。
- 文件夹图标、点选浏览、授权、预览和导入方式保持可用。浏览目录不自动执行 cd；只有明确点「在终端打开」「新终端」或「交给 Codex」才交接，并正确切到目标页面。
- 更新保留用户文件及 Codex 登录；不自动发送任务或扩大手机访问权限。

## 不做

- 本补充只接入已有会话能力，不实现多个独立 Codex 对话、Codex 工作目录选择和主题切换；这些仍由 2026-11-20-01 按原阶段完成。
- 不实现宽屏常驻文件树/左右分栏，不更改桌面端，不增加共享文件写回或挂载。
- 不在用户正在使用的真机上自动运行 instrumentation、清除数据、退出登录或重启应用；本轮先在独立模拟器完成自动测试并提供安装包验收。

## 怎样算做好

- 模拟器上文件快捷入口位于标题左侧，抽屉首项是文件；没有旧的三页标签和重复 Waddle 标题。小屏和宽屏窗口均能打开、选择、返回/遮罩关闭抽屉。
- 打开两个终端，通过抽屉切换及浏览文件后，原 Shell、输出、当前路径和运行任务保留；关闭确认可取消，只关闭指定终端。
- 文件目录浏览不改变终端 cwd；明确交接才切换目录/页面。交给 Codex 后显示尚未发送的路径，切到文件再返回、重建 Activity 后仍保留。
- Codex 未发送草稿、文件浏览位置和当前页面在切换/Activity 重建时保留；打开文件/抽屉不启动模型请求、不修改登录。
- Android 构建、lint、相关导航设备测试以及文件/终端回归通过；实现说明记录平台、结果、剩余限制，停下来等验收。

## 实现说明（实现者填写）

已实现，等待验收。

### 实现范围

- 新增 `ui/WaddleScreen.kt` 作为统一导航外壳：左侧菜单按钮和文件夹快捷按钮、单层当前页/会话标题、可收起的 Material 抽屉。文件是抽屉第一个固定项；下方单独列出现有 Shell 和 Codex，设置与帮助固定在底部。抽屉颜色沿用 Waddle 的绿色/深色配色。
- 删除旧「终端 / Codex / 文件」横排入口、终端内重复的品牌标题和 Shell 标签；终端当前路径移到统一标题栏。抽屉可新建终端、切换会话、确认关闭指定终端；仍最多 8 个终端。
- 抽屉不销毁后台 Shell 或 Codex 控制器。页面使用 SaveableStateHolder，保留 Codex 草稿和页面内可保存状态；选中文件在导航外壳保存，浏览控制器仍由服务持有，Activity 重建后继续使用。冷启动默认终端；不承诺系统杀进程后恢复 Shell 或未持久化的文件浏览位置。
- 文件页增加抽屉打开时禁用目录返回的条件，避免返回键穿透到目录导航；抽屉动画开始时即生效。打开抽屉时收起键盘并释放输入焦点，避免隐藏终端继续接收输入。标题保留可点击菜单入口，不仅依赖手势。关闭时仅左侧 16 dp 的触摸区响应右滑（超过 48 dp 打开），避免文件路径栏或终端自身横向手势争抢；展开后使用抽屉原生拖动关闭。
- Codex 的读取设置、亮度修改授权/开关、断开和运行环境说明集中到「设置与运行环境」；去掉主会话页的亮度测试快捷任务。原生工具、每次审批、停止、继续上次对话及登录实现不变。断开只由用户主动点击，不由切换页面触发。
- 更新主 README、Android README、图标许可归属。新增 folder/menu 使用 Material 图标，保留 Apache-2.0 说明。本轮未修改终端第三方源码、运行时或权限配置。

### 怎么试用

1. 打开应用，标题左侧文件夹按钮进入文件页；文件夹卡片、手机文件选择/授权、预览及导入方式与上一版相同。
2. 点菜单按钮打开抽屉。第一项「文件」，下一组是当前终端及 Codex。选择后抽屉收起；点遮罩或返回也可收起。
3. 在两个终端间切换，查看各自输出和路径。点会话旁 × 可取消或确认关闭；不会关闭其他 Shell。
4. 在文件页进入目录，终端 cwd 不变；点「在终端打开」才改变当前空闲 Bash 的 cwd，点「新终端」启动新 Shell，点「交给 Codex」显示尚未发送的本地路径。
5. 在 Codex 输入草稿，切到文件再切回来，或旋转/重建 Activity，草稿及未发送文件仍在。点「移除选择」只移除待发送路径，不删除文件。
6. 在抽屉底部打开设置和帮助。设置不会自行启动 Codex、发起登录、修改亮度或发送模型任务。
