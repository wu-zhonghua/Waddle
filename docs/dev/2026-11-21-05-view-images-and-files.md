# 在 Waddle 里看图片和文件：Codex 给的图直接显示，文件能预览、能用别的应用打开（2 个阶段）

- 状态：待实现（两个阶段一起做，中间不停下等验收）
- 日期：2026-11-21
- 上一份：无（基于 2026-11-20-03、2026-11-21-03、2026-11-21-04 已实现能力）
- 涉及：安卓

## 现在的样子

用户让 Waddle 里的 Codex 画图、截图或生成图片，Codex 回复里只给一个文件路径，对话里看不到图，路径也点不了。去文件页找到这张图，点开只提示「此文件不适合文本预览」。文件页现在只能预览文本文件，图片、PDF 等都打不开，也不能交给手机上的相册、PDF 阅读器等应用打开。Codex 生成的文件在 Waddle 自己的目录里，手机相册和其他应用看不到，用户没办法把结果拿出来用。

## 要做什么

用户在手机上让 Codex 干活，结果常常是图片或文件。用户要能在 Waddle 里直接看到结果，看不了的能交给手机上合适的应用，需要时能把文件拿到 Waddle 外面去用。

### 阶段 1：图片能看，文件能用别的应用打开、能分享

- Codex 对话里，Codex 生成或提到的图片（回复里给出的图片文件、Codex 运行过程中产出的图片）直接以缩略图显示在对应消息里。点缩略图全屏查看，能双指缩放、拖动，返回回到原来的对话位置。
- Codex 回复里提到的本机文件或文件夹路径可以点：图片直接看，文本文件按现有方式预览，文件夹在文件页打开，其他文件给出「用其他应用打开」。
- 文件页里点图片文件直接显示图片，不再提示不适合预览；常见格式都能看（png、jpg、webp、gif，包括手机相机拍的照片），大图不卡界面，能全屏缩放。
- 文件页和 Codex 对话里看文件时，都能「用其他应用打开」（交给手机上能打开这种文件的应用，比如相册、PDF 阅读器、WPS）和「分享」（发到微信、邮件等）。没有应用能打开时说清楚。
- Waddle 自己目录里的文件，能一键「保存到手机」（图片存进相册，其他文件存进下载），保存后在相册或手机文件应用里能找到；不覆盖手机里已有的同名文件，保存位置告诉用户。
- 文件不存在、已被删除、没权限读、格式坏了，都给出看得懂的提示，不闪退、不显示空白。查看文件时正在运行的终端和 Codex 任务不中断。

### 阶段 2：更多格式，终端里也能打开

- PDF 能在 Waddle 里直接翻页查看、缩放。
- 视频和音频能在 Waddle 里播放（能暂停、拖进度）。
- Markdown、HTML 等文本类文件除了看原文，也能看排版后的样子。
- 在终端里（包括直接在终端运行 `codex` 时）也能把一个文件打开到 Waddle 的查看页面，看完返回原终端，终端内容和正在跑的程序都还在。
- 阶段 1 的分享、用其他应用打开、保存到手机对这些格式同样可用。

## 不做

- 桌面端的任何改动。
- 编辑图片、PDF、Office 文档（只看，不改）；Waddle 内部直接预览 Office 文档（交给其他应用打开即可）。
- Codex 对话消息的整体排版（标题、表格、代码高亮等）。
- 用户从相册选图片发给 Codex 当输入（看图问问题），以后单独提。
- Codex 主动替用户保存或分享文件（属于 2026-11-20-02 阶段 3 的手机能力，那里每次要确认）。
- 云盘文件在线预览、自动同步到相册。

## 怎样算做好

### 阶段 1

- 在安卓模拟器和 Fold7 上，让 Codex 生成一张图片（例如用 Python 画一张图存成 png），对话里直接看到缩略图；点开全屏能缩放，返回回到原对话位置。
- Codex 回复里的文件和文件夹路径能点：图片显示、文本预览、文件夹在文件页打开、其他格式能用其他应用打开；路径含中文或空格也能打开。
- 文件页里打开 png、jpg、webp、gif 和一张手机相机拍的照片（在 Fold7 的相册目录里）都能正常显示；打开一张很大的图片时界面不卡、不闪退。
- 在 Fold7 上把 Codex 生成的图片「用其他应用打开」到相册、「分享」到一个聊天应用、「保存到手机」后在相册里看到；一个 PDF 能用其他应用打开；重复保存同名文件不覆盖旧的。
- 删掉或改坏一个文件后再点它的缩略图或路径，有看得懂的提示；查看文件前后，正在跑的终端命令和 Codex 任务都还在。
- 更新安装后用户文件和 Codex 登录保留；Android 构建和现有设备测试通过；桌面端照常能构建和测试。

### 阶段 2

- 模拟器和 Fold7 上，一个多页 PDF 能在 Waddle 里翻页、缩放。
- 一段视频和一段音频能在 Waddle 里播放、暂停、拖进度。
- 一个 Markdown 文件和一个 HTML 文件能切换看原文和排版后的样子。
- 在终端里（普通 Bash 和直接运行 `codex` 时各一次）把一张图片打开到查看页面，返回后终端内容和程序都还在。
- 更新安装后用户文件和 Codex 登录保留；Android 构建和现有设备测试通过；桌面端照常能构建和测试。
