# Waddle 改成 AI 终端：安装包不带 Codex，内置 AI 可选 DeepSeek 等国内模型（2 个阶段）

- 状态：验收不通过（阶段 1）
- 日期：2026-11-22
- 上一份：无（产品方向调整，之前的需求文档已全部删除）
- 涉及：安卓

## 现在的样子

安卓版把 Codex 和运行它要用的程序一起打包进了安装包。终端底部的“生成命令”、Codex 对话页面、文件夹里的“在这里打开 Codex”都依赖 Codex，要用 OpenAI 账号登录，国内网络一般连不上。我们要在国内上架，产品主打终端。

## 要做什么

Waddle 的定位是 **AI 终端**：终端是主体，AI 是终端里随时能用的能力，模型由用户自己选。Waddle 本体不带任何海外 AI 工具，国内用户装好就能用，不用翻墙。Codex、Claude Code 这类工具以后做成可选扩展，见 2026-11-22-02，这份不管。

### 阶段 1：去掉 Codex，接上内置 AI，能生成命令、能解释报错

1. **安装包里不再带 Codex。**界面里的 Codex 对话、Codex 登录、“在这里打开 Codex”这些入口都去掉。终端、多会话、文件浏览、“在这里打开终端”、看图片和文件、Bash、Git、curl 这些照常保留。
2. **设置里加“AI 模型”：**
   - 可以选的服务商：DeepSeek、通义千问、Kimi、智谱，再加一个“自定义（OpenAI 兼容）”，自己填接口地址。
   - 填 API Key，选模型。
   - 有“测试连接”按钮，能告诉用户成功了，或者失败的原因：Key 不对、余额不足、网络不通。
   - Key 只存在这台手机上，保存后不再明文显示，可以删掉。
3. **用一句话生成命令：**在终端底部用一句话说要做什么，AI 根据当前路径和最近的终端输入输出，给出命令和简短说明。命令可以修改，确认后在当前会话里执行，并且只执行一次。长命令和多行 Bash 都要支持。
4. **报错时让 AI 看看：**命令出错（退出码不是 0）后，终端里出现“让 AI 看看”。点了以后给出出错原因和修法；如果有修复命令，也要用户确认后才执行。
5. **没配 AI 也能用：**终端照常能用。点 AI 入口时，告诉用户先去设置里配模型，并直接带他过去。

### 阶段 2：AI 在终端里一步步做事

1. 用户给一个要好几步才能完成的任务（比如“把这个文件夹里的照片按月份分到子文件夹”），AI 在当前终端会话里一步一步地做。
2. 每一步先显示要运行的命令和为什么要运行它，用户同意了才执行。看到这一步的输出后，AI 再决定下一步做什么。
3. 用户可以拒绝某一步，也可以随时停下来。停下以后不再执行新的命令，正在跑的命令可以中断。
4. 做完以后给一个小结：执行了哪些命令，改了哪些文件。整个过程都留在终端里，可以往回翻。

## 不做

- Codex、Claude Code 等扩展（见 2026-11-22-02）。
- 桌面端。
- 读短信、通讯录、日历这类手机能力。
- Waddle 自己提供模型额度、账号或付费。
- 浅色/深色主题，以及之前需求里提过、这份没写的其他功能。
- AI 不经用户确认就执行命令。

## 怎样算做好

### 阶段 1

- 在安卓模拟器和 Fold7 上，新装的 Waddle 里找不到 Codex：抽屉、文件夹菜单、设置里都没有 Codex 入口；终端里敲 `codex` 会提示没有这个命令。安装包明显比现在小。
- 终端、多会话、文件浏览、在这里打开终端、看图片和文件、Bash、Git、curl 都照常能用。从旧版覆盖安装后，用户的文件还在。
- 在设置里能配好 DeepSeek：填 Key、选模型、测试连接成功。Key 填错、断网时，提示能看懂。DeepSeek 和至少一个自定义 OpenAI 兼容地址要在真机上实际跑通。
- 用一句话生成命令：建议和当前路径、最近的输出有关；命令可以编辑；确认后只在原来的会话里执行一次，`cd` 之后目录确实变了；取消生成、切换会话时，不会把过期的建议送到别的会话或正在运行的程序里。
- 故意运行一个会出错的命令，点“让 AI 看看”能看到原因和修法；修复命令确认后才执行。
- 在国内网络下不翻墙，用 DeepSeek 生成命令和解释报错都能用（需要用户在 Fold7 上确认）。GitHub 上的 Android 和 Desktop checks 都通过，桌面端照常能用。

### 阶段 2

- 在模拟器和 Fold7 上给一个多步任务（比如在一个测试文件夹里建 3 个子文件夹，再按扩展名把文件移进去）。AI 一步一步提出命令，每一步同意后才执行，最后结果正确。
- 拒绝某一步时，这一步不执行，AI 换一种做法或者结束。按停止后不再执行新命令，正在跑的命令能被中断。
- 任务结束时有小结，列出执行过的命令和改过的文件。
- AI 在一个会话里做事时，其他终端会话照常能用，不会收到误输入。
- 断网或 Key 失效时，任务停下来并说明原因，不会卡住。

## 实现说明（实现者填写）

### 2026-11-22 · 阶段 1

仅实现阶段 1；没有实现阶段 2，也没有实现 `2026-11-22-02`。沿用当前分支与工作目录，保留上一轮的离线运行时构建输入和哈希校验工作；没有 commit、push、tag、分支或 worktree 操作。

**做了什么**

- 安卓版本更新为 0.5.0（versionCode 5）。运行时不再生成/打包 Codex、code-mode helper 和 supervisor；生成的包清单、许可证也排除 Codex。Gradle 会拒绝旧的 Codex 生成物，防止未重新准备运行时就误打包。保留 Bash、Git、ripgrep、curl、HTTPS transport、证书和依赖库。
- 移除 Codex 对话、登录、抽屉新建对话、文件夹/文件查看器里的 Codex 入口，以及相关控制器、原生手机设置工具与 WRITE_SETTINGS 权限。后台服务仅持有终端；终端、多会话、文件浏览、打开终端、图片/PDF/文本/媒体查看和分享功能保留。
- 旧版覆盖安装只清理 Waddle 原先生成的 Codex/helper 符号链接，不清空 home、Imports、自定义 `.waddlerc` 或旧 `.codex` 文件。历史第三方包、锁和来源记录仍保留在仓库，但不会被本体安装或运行；这不是扩展实现。
- 「设置与运行环境」打开「AI 模型」：DeepSeek、通义千问、Kimi、智谱、自定义 OpenAI 兼容；支持预设模型选择、手填模型名、HTTPS Base URL/完整 Chat Completions 地址、测试连接、保存和删除 Key。各服务商单独保存配置；修改接口地址必须重填 Key，避免把原 Key 静默发送到另一个地址。
- Key 使用 Android Keystore AES-GCM 加密后放在应用私有配置中，禁用备份。输入时遮盖，保存后清空输入框，只显示已保存状态；不注入终端环境，不写进模型上下文或日志。API 错误转换为中文提示，区分 Key 失效、余额/额度、网络/TLS、限流、接口/模型不存在，不直接显示可能回显 Key 的服务端原文。
- 内置 AI 直接发非流式 HTTPS Chat Completions 请求，没有工具调用或执行通道。发送当前路径、最近 12,000 字符终端输入输出和最后退出码，发送前可以查看上下文。结果为说明与可编辑命令，允许长命令和最多 64 KiB 的多行 Bash。
- 沿用并加强原会话执行保护：校验会话、提示符轮次、cwd、前台进程/Readline 状态；确认后只提交一次，在原 Bash source 私有脚本，`cd` 和 export 保留。修正旧 shell 初始化中无效的 `vi-insertion` 键位名为 Bash 支持的 `vi-insert`，消除启动警告。停止、关闭面板、切换会话或 Activity 重建取消请求，过期返回及取消后的旧 UI 回调不能提交命令。
- Bash 在用户自定义提示符钩子之前记录退出码，钩子完成后才报告可输入状态。非零退出码显示「让 AI 看看」，打开后可分析原因和修法；修复命令仍需编辑/确认后运行。没有配置 AI 时两个入口均可直接跳到设置，终端仍可独立使用。
- 请求有连接/读取超时、两分钟总期限、回复大小限制，拒绝重定向、工具调用和被截断的回复。没有重试后自动执行、连续步骤或后台代理。修复 AI 底部面板的展开/键盘焦点竞态，面板展开完成后才自动聚焦。

**怎么跑起来与试用**

环境：JDK 17、Android SDK 36 / build-tools 36.0.0、NDK 28.2.13676358。

```sh
cd apps/android
python3 tools/prepare-runtime.py --ndk "$ANDROID_HOME/ndk/28.2.13676358"
./gradlew assembleDebug assembleDebugAndroidTest testDebugUnitTest lintDebug
adb -s DEVICE_SERIAL install --user 0 -r app/build/outputs/apk/debug/app-debug.apk
adb -s DEVICE_SERIAL shell am start --user 0 -n dev.waddle.android/.MainActivity
```

1. 不配置 AI，先试 `pwd`、`bash --version`、`git --version`、`curl --version`、`rg --version`；输入 `codex` 应报 command not found。抽屉新建/切换终端，文件夹「打开终端」，打开图片和文件。旧版请覆盖安装，不卸载或清除数据。
2. 点终端底部「问 AI，写命令」→「去设置」，或抽屉「设置与运行环境」。选择 DeepSeek，填本人的 Key、选择账号支持的模型（预设可选，也可手填），点「测试连接」后「保存」。测试使用当前表单，成功后仍需保存。测试会消耗少量服务商额度；Key 请只在手机里输入。
3. 再打开设置应只见「Key 已保存」，没有明文。可换 Key、删除 Key；用错误 Key 测试应有明确提示，断网再测试应提示网络问题。测试后恢复正确配置并保存。
4. 在终端进入一个测试目录，`ls` 后描述「进入刚才列出的子目录并打印路径」。先看上下文和建议，修改命令，再用运行按钮、硬件 Enter 或软键盘 Go 确认；Shift+Enter 换行。可用 `mkdir -p child`、`cd child`、`printf 'once\n' >> count` 三行验证目录保留、文件仅写一次。
5. 运行 `ls missing-waddle-file`，点「退出码 … · 让 AI 看看」→「分析报错」。原因和修法会显示在面板里；未确认前不会执行修复。可以修改建议或取消。
6. 生成过程中停止、切换会话，或让原终端运行其他命令后再确认，旧建议应失效。运行 `sleep 30`、`read` 或进入 Bash 续行状态时，不应把建议输入到该程序。
7. 自定义服务选择「自定义（OpenAI 兼容）」，填写 HTTPS 地址、模型与对应 Key，重复测试、生成和诊断。接口需支持 `/chat/completions`、system/user 消息及非流式文本回复；不支持 HTTP 明文或重定向。
