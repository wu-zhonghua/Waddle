# 文件页按位置浏览，优先直接在手机原目录工作

- 状态：验收通过
- 日期：2026-11-21
- 上一份：2026-11-20-03、2026-11-21-01、2026-11-21-02、2026-11-21-03
- 涉及：安卓

## 现在的样子

用户真机截图中，原 Lark 目录、导入成功副本卡片、重复目录标题和导入按钮占据同一页面。用户无法辨认自己正在浏览和操作哪一份文件。手机目录目前全部通过文档选择器访问，普通共享存储也被要求复制。

## 要做什么

- 文件入口先展示清楚的位置：手机存储、Waddle 文件、其他来源。进入后只保留一条位置路径、文件列表和当前文件夹的工作入口，其他管理功能收进菜单。
- 用户已明确选择「一起加入，优先操作原文件夹」。支持 Android 11+ 所有文件访问权限的系统授权入口，由用户手动开启；授权后可以浏览内部共享存储及可用存储卷，直接从普通目录打开终端/Codex，修改原文件，无需副本。
- 未授权、撤销权限、只读存储或存储设备移除时显示明确提示，不自动改用副本，不自动扩大权限。其他 App 私有目录继续受系统限制。
- 文档选择器保留为其他来源入口。不能提供真实目录的来源（如云盘）才提供明确复制流程；完成目录复制后立即进入副本位置，保留简短状态，清楚说明不回写原件。旧授权入口和旧副本保留。
- 当前目录只显示一套打开终端/Codex 操作。卡片以浏览为主，仍可通过目录操作菜单对所选目录打开会话。正在运行的会话、文件和登录不受界面切换影响。

## 不做

- 云盘挂载、自动同步/写回、副本自动删除、root、访问其他 App 的私有数据、自动授予真机权限。
- 更换登录、安装不同包名或分身、修改桌面端。

## 怎样算做好

- 文件首页可以区分三个来源；进入文件夹能明确判断当前位置，文件列表占据主要空间，没有原件/副本同时出现的工作按钮。
- 模拟器中验证未授权、授权后直接浏览与文件读写、权限撤销；终端和 Codex 运行时在同一共享目录工作，原目录出现结果且没有导入副本。
- 其他来源复制完成进入副本，来源与本地路径可区分，返回/切换位置不会显示上一目录遗留的成功卡片。
- 原有多会话、文件预览、导入取消及登录保留；构建、lint、针对性回归通过。
- 更新说明、截图与可安装包；真机覆盖安装仍只限主用户，权限交由用户手动开启。

## 实现说明（实现者填写）

### 界面审查与调整

基于用户提供的 [原始截图](../../artifacts/file-locations/01-before.jpg)，此次审查仅覆盖文件位置与工作目录流程：

1. 选择来源：原页将手机授权来源、Waddle 路径、添加文件和当前目录混在同一层。调整为独立的位置首页，明确区分手机存储、Waddle 文件、其他来源。
2. 浏览目录：原页重复出现 Lark 名称，导入卡片占据主要空间、遮挡文件。调整为一条面包屑、一条原件/副本标记、可滚动文件列表；输入路径、隐藏文件、刷新等放在菜单。
3. 开始工作：原件底栏与副本卡片同时提供动作，容易操作错对象。调整为当前目录底部唯一一组打开终端/Codex；单独选文件夹用卡片操作弹窗。复制完成后自动进入副本，状态用简短文字提示。

现有深绿主题与文件图标继续沿用。为目录操作补充明确的无障碍标签，避免弹窗按钮和背景按钮无法区分。截图只能支持结构、标签、密度判断；未据此宣称完整读屏或对比度合规。

### 直接访问原目录

- 声明 MANAGE_EXTERNAL_STORAGE，仅提供 Android 系统授权入口，不在应用内或真机上自动授予。Android 11+ 用户授权后枚举 StorageManager 的真实存储卷，普通共享目录直接打开终端/Codex。
- 原有系统授权来源保留。只对 `com.android.externalstorage.documents` 的平台文档 ID，用实际卷 ID、规范化边界与可访问性校验转换为目录；不猜测云盘/未知 provider 路径，拒绝路径穿越和越界链接。
- 未授权时显式拒绝直接共享存储浏览，防止 Android 的过滤列表被误认为空目录；返回应用时检查权限/存储卷变化并刷新，授权撤销或设备不可用不会触发自动复制。
- Waddle 私有文件照常使用；Android 8–10 保留原有私有目录与 SAF 流程，本轮不申请旧版广泛存储权限。Android/data、其他 App 私有数据和不可访问的存储位置不承诺支持。
- 只读卷可以读取和启动目录会话，写入失败由操作本身报错；此版本不承诺共享存储具有 Unix 的完整权限、符号链接或可执行文件语义。
- 复制流程仍使用原有原子发布、取消清理和大小/深度限制。成功后进入本地副本；进入其他目录或位置时清除旧提示。未删除已有副本、用户文件或登录。

技术依据：[Android 所有文件访问](https://developer.android.com/training/data-storage/manage-all-files)、[StorageVolume.directory](https://developer.android.com/reference/android/os/storage/StorageVolume#getDirectory())。正式上架前仍需按应用商店要求审核此权限；本轮没有发布行为。
